# Ramiz Naggar — Portfolio

A responsive personal portfolio for Ramiz Naggar, a Year 3 Computer Science student at the University of London, focused on AI/ML and software development.

## Contact form
The form is connected to FormSubmit and submits to **ramiz.naggar@gmail.com**. On the first real submission, FormSubmit may ask you to confirm/activate the recipient address. After activation, new enquiries are delivered to that inbox.

## WhatsApp
The WhatsApp button opens a chat with **+20 111 562 0044**.

## Run locally
Open `index.html` with VS Code Live Server or another local static server.

## Deploy
The site can be deployed to GitHub Pages, Netlify, Vercel, or any static host.
